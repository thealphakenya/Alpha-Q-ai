# QMOISPACE.md - QMOI Space Specification

## Overview
QMOI Space provides the live environment, media, and presentation layer needed for enhanced multimedia and dashboard experiences.

## Responsibilities
- media lifecycle management
- space orchestration
- live environment integration
- status and monitoring display
- presentation-layer feedback

## Alignment Rules
QMOI Space must maintain compatibility with the same validation, resilience, and coordination principles required by the rest of the QMOI system.
