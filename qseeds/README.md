# QSeed feature directory

This directory contains QSeed specifications and schemas only. The default
ciphertext vault and user-managed encryption keys are stored outside the
repository. Never place a plaintext seed, private key, recovery phrase, or
credential in this directory.

See [`../QSEED.md`](../QSEED.md) for the format, CLI, provenance, security
limits, audit policy, and recovery procedure.
